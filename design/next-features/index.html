Six features nobody else has.

Each one builds on what only this app has: your code runs in the browser in three languages, and any run can be recorded step by step. Every demo below is animated from a real trace of the code shown, computed in this page; the specs are in the .md files next to it.

Correction to the first pitch: Animate already has Compare with the reference (one variable), Break it (the app finds the bug) and a Measure meter. Features 01–03 build only what is missing.

    03

    Measure my Big-O: time and space

    build 3rddesign approved+ space merged from 12

    Run your passing code on sizes 8 … 4,096, count steps (not milliseconds), fit the usual classes and draw your curve next to the reference's. The same sweep also counts the extra memory your code holds, so you see both classes and the trade between them. "Beats 73%" is wall-clock noise; this tells you the class.

    ExistsMeasure meter: run.calls on the existing (mostly tiny) tests vs bigO(target), as a ratio table.
    NewCount-only runs (no snapshots, cap 5·10⁶), seeded generators from paramTypes, a least-squares fit, the hot line. Space: the same run tracks peak extra slots (your variables + sizes of arrays / Maps / Sets you create).
    Mount pointA lazy section at the bottom of the Complexity tab; one new count message in the worker.

    Measure my growth

    sizes 8 … 4,096 · seeded random inputs · step counts

    yoursreferencelog–log axes: a straight line's slope is the power of n
    Where you sit · time across, extra space up (bottom-left is best)

    Fit and generators
    • Candidates 1, log n, n, n log n, n², n³, 2ⁿ; fit on the larger half of the sizes; "between n and n log n" when two are within 0.02. The log–log slope is shown too.
    • Default generators per paramTypes; an optional growth.gen per question for sorted / structured inputs; worst: true for worst-case.
    • Space: peak of (live local variables + lengths / sizes of arrays, Maps, Sets and objects your code allocated) per run; the input itself and memory inside built-ins (e.g. sort) are not counted, and the chart says so. Fitted on the same candidates.
