Nine more ideas nobody ships.

Each one builds on what this app already records: every run, step by step, with the variables at each step. Every demo below is animated from code that really runs in this page.

Research check: LeetCode's Code Replay replays contests, not your growth. Loop-invariant tools (GLI / CAFÉ) check drawings, not your run. Sonification studies (SIGCSE 2022, 2024) used instructor code, never the student's. Space measurement exists only in research tools (Munin, EMA), so it now lives inside 03. Invariant pins

top pick

Pin one line of JS that must stay true inside the loop. It is checked at every recorded step, and the first step that breaks it is marked, often long before the wrong answer comes out.

ExistsEvery recorded step has the variables in scope.
NewEvaluate the pin against each step's variables in the worker; stop at the first false.
Mount pointA pin field above Animate's player; pins saved per question.

Hear your code

later

Each read plays its value as a note. A quadratic run sounds like a long scrape; a linear one is a short phrase. It also gives learners who can't see the animation a way in.

ExistsEvery recorded step has an op (read, write, compare).
NewTurn the ops into notes with Web Audio (built into the browser). Never autoplays.
Mount pointA speaker toggle in the run player.

Trace twins

optional

Every site groups questions by tags. This groups them by how the solution actually moves: plot each pointer's index over time, and questions with the same shape are twins.

ExistsReference solutions for every question.
NewA build script records each reference run's pointer moves and compares shapes. Zero runtime cost.
Mount pointA "Moves like" row under a question's title.
